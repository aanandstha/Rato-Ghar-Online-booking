# Week 6 — UI/UX Design

## Expected Deliverable

Design responsive and user-friendly interfaces for the Food Ordering Website system.

---

# Objective

The objective of this phase was to create an intuitive and visually appealing user interface that enhances user experience and simplifies the online food ordering process for customers and administrators.

---

# Activities Completed

- Created wireframes for the application
- Designed customer and admin interfaces
- Defined navigation and user flow
- Designed reusable UI components
- Planned responsive layouts for mobile and desktop devices
- Improved usability and accessibility considerations

---

# Main Screens Designed

## Customer Interfaces

| Screen | Description |
|---|---|
| Home Page | Displays featured restaurants and food items |
| Login/Register Page | Allows users to create accounts and login |
| Restaurant Listing Page | Displays available restaurants |
| Food Menu Page | Shows food items with prices and details |
| Cart Page | Displays selected items before checkout |
| Checkout Page | Handles delivery and payment details |
| Payment Page | Processes customer payments |
| Order Tracking Page | Tracks order preparation and delivery |
| User Profile Page | Manages account details and order history |

---

## Admin Interfaces

| Screen | Description |
|---|---|
| Admin Dashboard | Displays overall system statistics |
| Manage Restaurants | Add, update, or remove restaurants |
| Manage Food Items | Manage menu items and pricing |
| Manage Orders | Track and update order status |
| Manage Users | View and manage customer accounts |
| Payment Reports | Monitor payment transactions |

---

# User Navigation Flow

```text
Home Page
   ↓
User Login/Register
   ↓
Browse Restaurants
   ↓
View Food Menu
   ↓
Add Items to Cart
   ↓
Checkout
   ↓
Payment Processing
   ↓
Order Confirmation
```

# Wireframe Design Overview

## Home Page

The Home Page was designed to provide users with quick access to featured restaurants, popular food items, and navigation options.

### Features
- Navigation bar
- Search functionality
- Featured restaurants section
- Popular dishes section
- Footer section

---

## Restaurant Listing Page

The Restaurant Listing Page displays all available restaurants in a clean card-based layout.

### Features
- Restaurant cards
- Restaurant ratings
- Search and filter options
- Restaurant images

---

## Food Menu Page

The Food Menu Page allows customers to browse menu items and add them to the cart.

### Features
- Food categories
- Food cards with images
- Price and rating display
- Add-to-cart functionality

---

## Cart Page

The Cart Page provides an overview of selected food items before checkout.

### Features
- Quantity adjustment
- Remove item option
- Total price calculation
- Checkout button

---

## Checkout Page

The Checkout Page handles delivery information and payment confirmation.

### Features
- Delivery address form
- Payment method selection
- Order summary
- Confirm order button

# Design Principles Applied

The following UI/UX principles were considered during the design process:

- Responsive design for multiple devices
- Simple and intuitive navigation
- Consistent color scheme and typography
- User-friendly interface layout
- Accessibility and readability
- Minimalistic modern design approach
